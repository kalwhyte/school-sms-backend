# School Student Management System (SMS) Project

## Overview
The School Student Management System is a comprehensive software solution designed to streamline administrative tasks and manage student data efficiently. It serves as a centralized platform for teachers, administrators, and parents.

## Key Features
- **Student Information Management:** Digital profiles containing personal details, enrollment history, and contact information.
- **Attendance Tracking:** Real-time monitoring of daily attendance with automated notification triggers for parents.
- **Gradebook & Academic Records:** Tools for teachers to input grades, calculate GPAs, and generate digital report cards.
- **Fee Management:** Automated billing, online payment integration, and tracking of outstanding balances.
- **Communication Portal:** Integrated messaging system for school-wide announcements and direct teacher-parent communication.

## Technical Stack
- **Backend:** Nest.js
- **Database:** PostgreSQL
